# プライバシー

このWikiでは、サイトの利用状況を把握するために **Cloudflare Web Analytics** を使用します。

## 取得する情報

Cloudflare Web Analyticsにより、次のような統計情報が処理される場合があります。

- 閲覧されたページ
- 参照元
- 国・地域
- ブラウザ
- OS
- 端末種別
- 閲覧日時

## Cookie

このWikiに組み込むCloudflare Web Analyticsは、サイト解析のためのCookieを使用しない構成です。

## 利用目的

取得した統計情報は、次の目的に使用します。

- よく読まれている記事の把握
- Wiki構成の改善
- 説明不足のページの発見
- 日本語・英語ページの需要把握
- ゲーム情報の提供改善

## 外部リンク

このWikiにはMicrosoft Store、X、YouTubeなど外部サイトへのリンクがあります。外部サイトでは、それぞれのプライバシーポリシーが適用されます。
