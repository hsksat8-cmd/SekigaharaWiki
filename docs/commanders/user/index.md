# ユーザー武将

[English version](../../en/commanders/user/index.md)

ユーザー武将は、プレイヤーが任意に戦闘へ追加できる参加枠です。東軍・西軍のどちらにも配置でき、最大3隊まで追加できます。

!!! note "体験版"
    体験版では追加・指示できるのはユーザー武将1のみで、兵数は10,000人固定です。また、選択できるシナリオは「小早川・毛利静観」のみです。

通常版の兵数設定上限については、[ユーザー指定による兵数追加の制限](../../gameplay/subscenarios.md#ユーザー指定による兵数追加の制限)を参照してください。
