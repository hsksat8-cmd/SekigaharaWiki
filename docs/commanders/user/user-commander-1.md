## 特徴

東軍・西軍のどちらにも配置でき、最大3隊まで追加可能です。

## 設定できる項目

- 名前
- 英語名
- 位置
- 兵数
- 待機ターン
- 目標（敵部隊またはマップ座標）
- 目標保持ターン
- 初期陣形
- 陣形維持ターン

## 補足

ユーザー武将1・2・3は、プレイヤーが任意に参加武将を追加するための枠です。基本能力は共通で、配置先の軍や設定内容によって役割を変えられます。
