# Version 2.7.0

[English version](../en/updates/v2.7.0.md)

## 更新内容

- 部隊の兵種として**通常**と**全騎馬**を選択できるようになりました。
- 全騎馬部隊では、バランス調整のため兵数が**15%削減**されます。
  - 例：5,000人の部隊を全騎馬にすると、4,250人になります。
- 全騎馬部隊の兵数を増加させる場合、軍ごとの兵数増加枠を**1.15倍**消費します。
  - 例：全騎馬部隊を1,000人増加させると、兵数増加枠を1,150人消費します。
- 全騎馬を選択できるのは、兵数**6,600人以下**の部隊です。
- 騎馬の移動速度が足軽の**1.5倍**になりました。
- 部隊得点の計算を、戦闘開始時の兵数で正規化する方式に変更しました。
- タイトル、メニュー、ログ欄、状況欄を折りたためるようになりました。
- 武将の兵数を次のように変更しました。
  - 前田利長：**15,100**
  - 伊達政宗：**14,100**
  - 丹羽長重：**3,700**
  - 山内一豊：**3,000**
- 架空大戦系シナリオでは、中規模の4部隊がランダムに全騎馬部隊になり、戦いごとの変化を楽しめるようになりました。
- 部隊の挙動をより自然にしました。

## 部隊得点

部隊得点は次の式で計算されます。

**部隊得点 =（討ち取った兵数 − 失った兵数）÷ 戦闘開始時の兵数 × 10,000 ＋ 討ち取った武将数 × 3,000 ＋ 討ち取った大将数 × 10,000 − 討ち取られた武将数 × 3,000 ＋ 勝利ボーナス**

勝利ボーナスは、通常の勝利では**10,000点**、午後8時時点の兵力優勢による勝利では**3,000点**です。

全騎馬部隊の詳しい仕様は[全騎馬部隊](../systems/all-cavalry-units.md)、得点については[戦績とランキング](../gameplay/results-and-rankings.md)を参照してください。
