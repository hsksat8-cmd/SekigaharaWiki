## Version 1.2.0
- 任意の時点で東軍または西軍としてユーザーが参加して、いずれかの軍のすべての武将を操作できるようになりました。またユーザー武将を含めて、最大3人の武将として参加できます
- 武将を削除して、少数の部隊による決戦を行うことができるようになりました（徳川家康隊と石田三成隊は削除できません）
- リアルタイムで字幕が表示され、戦況を盛り上げるとともに、容易に状況を把握できるようになりました
- 勝敗後に戦績表で、各武将の戦績とランキングを見ることができるようになりました。各戦いで得られた得点の累積によるランキングも表示されます。さらにシナリオ・サブシナリオ別の東西両軍の総合得点が表示され、合わせて過去の上位5得点も表示されます
- 各部隊の挙動がより自然になりました
- [詳細](v1.2.0.md)

## Version 1.1.0

- 新たに追加された2つのランダムシナリオでは、部隊の兵数もランダムに増減します
