# Version 2.2.0

## 確認できた主な変更

- 方形、方形自由、鶴翼、縦深、魚鱗の5陣形を追加
- 方形自由を既定陣形に設定
- 方形自由以外は、敵に接するまで最大50ターン陣形を維持
- 陣形ごとの相性と規模差への適性を設定
- 士気低下時に一時撤退する行動を追加
- ゲーム的な合理性だけでなく、戦国時代の武将らしい動きへ部隊挙動を調整
