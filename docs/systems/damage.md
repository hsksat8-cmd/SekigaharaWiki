# ダメージ計算

戦闘のダメージ／被ダメージには、次の重みが関係します。

## 攻撃側

| 要素 | 比率 |
|---|---:|
| 部隊攻撃力 | 46% |
| 部隊士気 | 18% |
| ドット士気 | 28% |
| 規律 | 8% |

## 防御側

| 要素 | 比率 |
|---|---:|
| 部隊防御力 | 48% |
| 部隊士気 | 18% |
| ドット士気 | 26% |
| 規律 | 8% |

## Version 2.8.0：時間経過と疲労

Version 2.8.0から、**全兵士ドットのHPは時間経過とともに疲労によって減少**します。敵の攻撃を直接受けていないドットにも疲労によるHP減少が発生します。

疲労によるHPの具体的な減少率や更新式は本更新情報では指定されていません。
