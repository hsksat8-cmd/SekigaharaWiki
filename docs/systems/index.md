# 戦闘システム

戦闘結果は兵数だけでは決まりません。主な要素は次のとおりです。

- 兵種
- 部隊兵種（通常／全騎馬）
- 部隊攻撃力・部隊防御力
- 部隊士気
- 兵士ドットごとの士気
- 規律
- 疲労
- 包囲
- 戦況
- 陣形
- 部隊の分断と各個撃破

Version 2.7.0から、部隊兵種として**通常**と**全騎馬**を選択できます。詳しくは[全騎馬部隊](all-cavalry-units.md)を参照してください。

各項目の詳しい説明は、この節の個別ページを参照してください。

Version 2.8.0からは、[側面・背面接敵による戦術制限](flank-rear-engagement.md)と[士気低下](morale.md)、時間経過による[兵士ドットの疲労HP減少](damage.md)が加わりました。
