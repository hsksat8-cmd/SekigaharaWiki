# 包囲と中央突破

## ドット単位の包囲

兵士ドット単位では、包囲は明確に有利です。

## 部隊単位の包囲

部隊単位では、包囲には利点と危険の両方があります。

### 利点

- 相手の士気を低下させられる
- 接敵面を増やせる
- 退路を圧迫できる

### 危険

- 自軍の兵力が分散する
- 中央が薄くなる
- 相手の中央突破で戦況を一気に決められる場合がある

大将部隊が弱い西軍は包囲を選ぶ必要が生じやすい一方、徳川家康隊のような強い大部隊による中央突破への警戒が必要です。
