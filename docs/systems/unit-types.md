# 兵種

[English version](../en/systems/unit-types.md)

兵士ドットには次の兵種があります。

| 兵種 | 特徴・長所 | 短所・注意点 |
|---|---|---|
| 槍足軽 | 基本兵種。標準HPで近接戦を担う。敵鉄砲足軽が距離4以内なら、士気に関係なく最も近い敵鉄砲足軽へ10ターン突撃する。鉄砲足軽の護衛にも割り当てられる。 | 遠距離攻撃はない。鉄砲足軽の射撃圏に入るまで被弾しうる。低士気で敵鉄砲足軽が近い場合は安全な味方側へ後退する。 |
| 鉄砲足軽 | 射程1～4。近いほど命中率・威力が上がる。味方が射線上におらず、目標が味方と近接戦になっていなければ発砲する。4ターンごとに射撃可能。 | HPは槍足軽の70%。距離1未満の相手には撃てず、接近されると後退する。味方と接敵している敵は誤射防止のため撃たない。護衛がいないと槍足軽・騎馬の突撃を受けやすい。 |
| 騎馬 | 通常の槍足軽のHPの1.5倍。敵鉄砲足軽への突撃要員になれ、鉄砲足軽の護衛にも割り当てられる。護衛時は味方鉄砲足軽の周囲にいて、敵が距離1以内まで来れば迎撃する。 | 現状は、通常移動上限や近接攻撃力そのものに槍足軽より高い専用補正はない。初期配置では一般兵の約10%が騎馬。 |
| 武将ドット | 部隊中心にいる高耐久の指揮中枢。通常兵よりHPが高く、部隊の旗印が常時表示される。 | 鉄砲足軽・騎馬ではなく、対鉄砲足軽突撃や鉄砲護衛の通常兵ロジックの対象外。孤立や危険時には生存優先の挙動を取る。 |
| 大将ドット | 武将よりさらに高耐久の部隊中枢。大将が討ち取られると戦局への影響が大きく、旗も通常兵より大きく表示される。 | 武将同様に一般兵の兵種ロジックとは別扱い。孤立すると後退・護衛優先の処理が働く。 |
