# 部隊規模と各個撃破

## 総兵数だけではドット同士の強さは決まらない

投稿では、各部隊の総数そのものはドット対ドットの戦闘へ直接影響せず、個々の戦闘には部隊の戦闘力、防御力、士気などが影響すると説明されています。

したがって、大部隊であるだけで、目の前の1対1が自動的に有利になるわけではありません。

## 大部隊の強み

大部隊が孤立した小部隊を各個撃破すると、絶対的な損失を与えやすくなります。徳川家康隊単独3万人対西軍主力3万3,600人の検証では、徳川隊が西軍部隊を順番に撃破する展開が示されています。

## 小部隊の強み

Version 2.2.0の撤退行動により、小部隊は機敏に押し引きを繰り返し、複数部隊で1つの大部隊へ対抗しやすくなりました。
