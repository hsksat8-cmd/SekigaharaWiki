# 士気

士気は、兵力と並んで勝敗を左右する重要な要素です。

## 士気が変化する要因

投稿では、士気は次の状況で変化すると説明されています。

### 上昇しやすい状況

- 戦闘で優勢になる
- 勝利が近づく
- 敵を押し込む

### 低下しやすい状況

- 負けが込む
- 疲労が蓄積する
- 戦況が悪化する
- 包囲される
- 正面から強い敵にぶつかる

士気が低下すると、その部隊の兵力が急速に削られやすくなります。

## Version 2.2.0の撤退行動

Version 2.2.0では、部隊の士気が低下したときに一時撤退する行動が追加されました。小部隊が士気0のまま急速に壊滅するのを避け、撤退と攻撃を繰り返しやすくする意図があります。
