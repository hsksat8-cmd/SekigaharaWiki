# 全騎馬部隊

[English version](../en/systems/all-cavalry-units.md)

Version 2.7.0から、部隊の兵種として**通常**と**全騎馬**を選択できます。

ここでいう「部隊の兵種」は、個々の兵士ドットの兵種とは別の、部隊全体の編成方式です。

## 通常部隊

通常部隊は、従来どおり槍足軽・鉄砲足軽・騎馬などで構成される部隊です。

## 全騎馬部隊

全騎馬を選択すると、その部隊は全騎馬部隊として編成されます。

全騎馬部隊には、機動力の高さとのバランスを取るため、次の制約があります。

| 項目 | 仕様 |
|---|---|
| 選択可能な兵数 | **6,600人以下** |
| 全騎馬化時の兵数 | 元の兵数から**15%削減** |
| 兵数増加枠 | 増加人数の**1.15倍**を消費 |
| 騎馬の移動速度 | 足軽の**1.5倍** |

### 兵数の例

5,000人の通常部隊を全騎馬にすると、

**5,000 × 0.85 = 4,250人**

となります。

### 兵数増加枠の例

全騎馬部隊の兵数を1,000人増加させる場合、

**1,000 × 1.15 = 1,150人**

として、軍ごとの兵数増加枠を1,150人消費します。

## 架空大戦系シナリオ

架空大戦系シナリオでは、中規模の**4部隊**がランダムに全騎馬部隊になります。

これにより、同じシナリオでも全騎馬となる部隊が変わり、戦いごとの展開に変化が生まれます。全騎馬となった部隊には、上記の15%の兵数削減が適用されます。

## 得点との関係

Version 2.7.0では、部隊得点の兵数に関する部分を**戦闘開始時の兵数**で正規化するようになりました。

このため、全騎馬化によって兵数が15%減少した部隊も、単純な絶対兵数だけではなく、その部隊の開始兵数に対する戦果で評価されます。

詳しくは[戦績とランキング](../gameplay/results-and-rankings.md)を参照してください。
