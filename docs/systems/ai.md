# 部隊AI

[English version](../en/systems/ai.md)

部隊は士気、疲労、位置関係、戦況などに応じて自律的に行動します。

## Version 2.1.0

部隊の挙動をより自然なものに修正しました。

## Version 2.2.0

ゲーム的な合理性だけでなく、戦国時代の武将らしい動きに寄せるよう部隊挙動を修正しました。低士気時の一時後退も追加されています。

## シナリオによる参戦判断

参戦・静観・寝返りの条件はシナリオによって異なります。**史実寄り**では小早川・毛利・島津などが戦況に応じて行動し、**小早川静観**や**毛利積極参戦**などの固定シナリオでは特定勢力の行動条件が変更されます。ランダム戦では参戦時期や武将特性などに乱数要素が加わります。詳しくは[シナリオ一覧](../scenarios/index.md)を参照してください。

## Version 2.6.1：部隊戦術

各部隊に、**突撃・攻撃的・通常・守備的・後退**の戦術を設定できるようになりました。サブシナリオの初期設定として保存できるほか、戦闘中も指示可能な部隊へユーザー指示として変更できます。

戦術は攻撃力や防御力を直接補正するものではなく、既存の状況判断で選ばれた行動を攻勢・守勢方向へ変化させます。

| 戦術 | 行動傾向 |
|---|---|
| 突撃 | 一般部隊は常に攻撃、大将部隊は常に前進を選ぶ |
| 攻撃的 | 防御→支援、支援→前進、前進→攻撃と、判断を1段階攻勢側へ変更 |
| 通常 | 通常の状況判断をそのまま使用 |
| 守備的 | 攻撃→前進、前進→支援、支援→防御と、判断を1段階守勢側へ変更 |
| 後退 | 常に後退を選ぶ |

実験資料では「守備的」に相当する戦術が「防御的」と表記されています。比較結果は[部隊戦術実験](unit-tactics-experiment.md)を参照してください。
