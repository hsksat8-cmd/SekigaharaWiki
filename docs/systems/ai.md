# 部隊AI

部隊は自律的に行動し、士気、疲労、位置関係、戦況などに応じて前進・後退・参戦判断を行います。

## Version 2.1.0

Version 2.1.0では、部隊の挙動をより自然なものへ変更したです。

## Version 2.2.0

Version 2.2.0では、ゲーム的な合理性だけではなく、戦国時代の武将らしい動きへ寄せる方向で修正されました。また、士気低下時の一時撤退が追加されています。

## 参戦判断

史実寄りのシナリオでは、小早川秀秋、毛利秀元、吉川広家、島津義弘などが戦況を見て参戦するかどうかを判断します。ランダム系シナリオでは、戦況との関係が弱いランダムな参戦になります。
