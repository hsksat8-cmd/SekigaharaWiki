# ゲーム概要

「関ヶ原IF布陣シミュレータ」は、関ヶ原の戦いを複数の条件で再現し、部隊の自律的な行動と戦況の変化を観察するゲームです。

## 基本的な考え方

部隊は、単純な兵数だけでなく、次の要素の影響を受けます。

- 部隊攻撃力・部隊防御力
- 部隊士気
- 個々の兵士ドットの士気
- 武将の統率
- 疲労
- 包囲や位置関係
- 戦況の有利・不利
- 陣形

関ヶ原を史実寄りに再現するシナリオのほか、参戦条件や兵数・能力が変化するIFシナリオがあります。

## 画面表現

Version 2.0.0では関ヶ原の地形表現が更新され、拡大モードでは兵士のアニメーションが表示されるようになりました。兵士の向きが見えるため、戦闘の流れを視覚的に把握しやすくなっています。

- Ctrl＋左クリック：拡大モード
- Ctrl＋マウスホイール：表示倍率を1～50倍に変更
