# ゲーム概要

[English version](../en/game/overview.md)

「関ヶ原IF布陣シミュレータ」は、東西両軍の武将と兵士たちが多数のドット、または兵士アニメーションとなって戦う、観戦主体の布陣シミュレーションゲームです。

戦闘開始後は各部隊が目標や戦況に応じて自律的に行動します。作業中に画面の片隅で戦況の変化を眺めたり、布陣やシナリオを変更して異なる結末を比較したりできます。


## ゲームの中心となる考え方

勝利の鍵は、兵力だけではなく、部隊の位置関係と戦力の集中です。

本隊の戦力で劣る西軍は、複数部隊で敵を取り囲む包囲や、孤立した敵部隊を順番に倒す各個撃破が有効です。一方、本隊の強力な東軍は、徳川家康隊を中心とした中央突破によって敵大将を直接狙えます。

戦況や布陣によって有効な戦略は変化します。

- 敵大将への進軍を優先する
- 味方大将を守る
- 敵部隊を包囲して戦力を削る
- 孤立した部隊を各個撃破する
- 中央突破によって短期決着を狙う

初期配置の違いが、その後の戦局を大きく左右します。

## 主な特徴

| 分類 | 内容 |
|---|---|
| 合戦表現 | 多数の兵士ドット、または兵士アニメーションによる大規模戦闘 |
| 表示単位 | 1ドットまたは1キャラが10人または20人に対応 |
| 部隊行動 | 武将や部隊が目標と戦況に応じて自律的に行動 |
| 参加方法 | 観戦、東軍参加、西軍参加の3モード |
| 陣形 | 方形、方形自由、鶴翼、縦深、魚鱗 |
| 戦略 | 包囲、各個撃破、中央突破など |
| 配置編集 | 部隊をドラッグして初期配置を変更 |
| サブシナリオ | 武将配置、初期目標、初期待機時間を保存 |
| データ共有 | サブシナリオ群のインポート・エクスポート |
| 観戦支援 | リアルタイム字幕、武将詳細の切り替え |
| 戦績 | 武将別戦績、ランキング、累積得点、陣営別得点 |
| 表示操作 | 拡大モード、1～50倍の倍率変更 |
