  <div class="stat-card"><strong>自律的な部隊</strong><br>部隊は士気、位置関係、戦況などに応じて行動します。</div>
  <div class="stat-card"><strong>IFシナリオ</strong><br>小早川秀秋の静観・西軍参加や、ランダム化された戦況を試せます。</div>
