# 基本戦術

[English version](../en/gameplay/tactics.md)

## 兵力より位置関係と集中

勝敗は総兵力だけでは決まりません。部隊がどこに配置され、どの敵へ戦力を集中できるかが重要です。

## 西軍の包囲と各個撃破

本隊の戦力で劣る西軍では、次の戦術が有効です。

- 複数部隊で敵を取り囲み、士気を低下させる
- 孤立した敵部隊を順番に倒す
- 敵の中央突破を警戒しながら、側面から圧力をかける
- 味方大将の周囲を薄くしすぎない

正面・背面からの挟撃について、陣形や鉄砲足軽比率などを比較した結果は[挟撃総合実験](../experiments/pincer/index.md)を参照してください。

## 東軍の中央突破

本隊が強力な東軍では、徳川家康隊を中心に中央を突破し、敵大将を直接狙う戦略を取れます。

ただし、中央突破に戦力を集中しすぎると、側面の部隊が孤立する場合があります。

## 敵大将か敵部隊か

状況に応じて、次の優先順位を切り替える必要があります。

- 敵大将への進軍を優先する
- 味方大将を守る
- 包囲を完成させる
- 孤立した敵部隊を各個撃破する
- 退路を確保する

## 初期配置の重要性

部隊はドラッグして初期配置を変更できます。配置のわずかな違いでも、最初に接触する相手や包囲の成立、中央突破の成否が変わります。

## 部隊戦術の使い分け

Version 2.6.1から、サブシナリオと戦闘中のユーザー指示で、各部隊の戦術を**突撃・攻撃的・通常・守備的・後退**から選択できます。

戦術の効果は単純な強弱ではなく、部隊に求める役割によって変わります。今回の比較実験では、1対1では「攻撃的」が比較的安定し、挟撃では正面部隊を「通常」、背面部隊を「突撃」とした組み合わせが最も高い西軍勝率を示しました。

詳しい条件と結果は[部隊戦術実験](../systems/unit-tactics-experiment.md)を参照してください。

実験結果をまとめて見る場合は[実験一覧](../experiments/index.md)を参照してください。
