# 基本戦術

## 士気を先に崩す

兵力に勝る敵へ正面からぶつかると、自軍の士気が先に崩れやすくなります。戦闘では兵数だけでなく、相手の士気を下げる位置取りと戦い方が重要です。

## 孤立した敵を各個撃破する

大部隊は、兵数が多いだけで個々の戦闘が自動的に有利になるわけではありません。しかし、孤立した小部隊を順に攻撃する各個撃破では、大きな破壊力を発揮します。

## ユーザー武将は局所投入する

5,000人規模のユーザー武将は、大部隊との正面戦闘では不利です。次の機会を狙います。

- 孤立した敵部隊
- 敵大将の孤立
- 味方が押している局面
- 地形上有利な場所からの参戦

## 包囲と中央突破を使い分ける

包囲は相手の士気を下げますが、自軍を分散させます。相手の中央突破を許すと、戦況を一気に決められる危険があります。
