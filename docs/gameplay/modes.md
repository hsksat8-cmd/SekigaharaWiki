# プレイモード

[English version](../en/gameplay/modes.md)

戦闘中、ユーザーは任意の時点で次の3つのモードにより参加できます。部隊を右クリックして指示します。

## ユーザー武将以外は観戦モード

同陣営の最大3人のユーザー武将、または実在武将に指示できます。

- ユーザー武将には自由に名前を付けられる
- それ以外の部隊は自律行動を続ける
- 少数の部隊だけに介入しながら、全体の戦況を観察できる

## 東軍で参加モード

東軍の全武将に指示できます。

徳川家康隊を中心とした中央突破や、複数部隊による敵大将への集中攻撃などを試せます。

## 西軍で参加モード

西軍の全武将に指示できます。

包囲、各個撃破、味方大将の防衛など、複数部隊を連携させる指揮が重要になります。

## 観戦から介入へ

このゲームは観戦主体ですが、必要な場面だけ指示を出すこともできます。作業中は自律戦闘を眺め、戦況が大きく動いたときだけ介入する遊び方にも向いています。
