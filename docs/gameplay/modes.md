# プレイモード

ユーザーが参加できるモードとして、X投稿では次の3種類が説明されています。

| モード | 指示できる範囲 |
|---|---|
| ユーザー武将以外は観戦モード | 同陣営のユーザー武将を含む最大3人の武将 |
| 東軍で参加モード | 東軍の全武将 |
| 西軍で参加モード | 西軍の全武将 |

観戦中心で戦況を見守ることも、陣営全体を指揮することもできます。

## ユーザー武将

ユーザー武将は自由に名前を付けて戦場へ参加できます。投稿では、ユーザー武将が5,000人の中規模部隊を率いる例が説明されています。

大部隊へ正面から挑むよりも、山頂などで待機し、孤立した敵部隊や敵大将を狙って局所的に参戦する運用が推奨されています。
