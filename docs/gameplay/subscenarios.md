# サブシナリオ

[English version](../en/gameplay/subscenarios.md)

ユーザーが調整した条件を、サブシナリオとして保存できます。

## 保存できる内容

サブシナリオでは、次の操作ができます。

- 作成した武将の配置
- 初期目標
- 初期待機時間

## 初期配置の変更

部隊をドラッグして初期配置を自由に変更できます。配置によって、接敵順序、包囲、中央突破、味方大将の防衛状況が変化します。

## インポートとエクスポート

サブシナリオ群のインポート・エクスポートに対応しています。

これにより、作成した条件を保管したり、複数の設定をまとめて移動したりできます。
