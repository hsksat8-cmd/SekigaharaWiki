# サブシナリオ

[English version](../en/gameplay/subscenarios.md)

ユーザーが調整した条件を、サブシナリオとして保存できます。

## 保存できる内容

サブシナリオでは、次の操作ができます。

- 作成した武将の配置
- 初期目標
- 初期待機時間

## 初期配置の変更

部隊をドラッグして初期配置を自由に変更できます。配置によって、接敵順序、包囲、中央突破、味方大将の防衛状況が変化します。

## インポートとエクスポート

サブシナリオ群のインポート・エクスポートに対応しています。

これにより、作成した条件を保管したり、複数の設定をまとめて移動したりできます。

## ユーザー指定による兵数追加の制限

- 既存の武将隊は、徳川家康隊を除き1隊最大20,000人です。
- ユーザー武将も1隊あたり最大20,000人です。
- 徳川家康隊には1隊20,000人の上限はありません。ただし、東軍への手動増員は合計+15,000人までのため、基準兵数30,000人から増やせる上限は45,000人です。
- 手動で増やせる兵数は、東軍・西軍それぞれ基準兵数から合計で最大+15,000人です。
- ユーザー武将の兵数は、その全量が所属軍の+15,000人枠を使用します。
- 既存部隊を増員した分も同じ枠を使います。部隊を減員しても、その分の増員枠は復活しません。
- 上限を超える指定は自動調整され、「各隊2万人上限」と「各軍+1万5千人上限」を区別したメッセージが表示されます。
