# キーボード・マウス操作

[English version](../en/gameplay/controls.md)

## マウス操作

| 操作 | 内容 |
|---|---|
| 左クリック | 部隊・武将・UI項目を選択 |
| 左ドラッグ | 部隊の初期配置を移動 |
| `Ctrl` + 左クリック | 兵士アニメーションの表示／非表示を切り替え |
| `Ctrl` + マウスホイール | マップを拡大・縮小 |
| 右クリック | 部隊への移動先・攻撃目標などを指定 |
| マップ上をドラッグ | 表示位置を移動 |

## キーボード操作

| キー | 内容 |
|---|---|
| `Esc` | 選択解除、メニューを閉じる |
| `Space` | 一時停止／再開 |
| `←` / `→` | 選択中の武将を切り替え |
| `Shift` | 吹き出しデータを非表示 |
| `Ctrl` | カーソルを非表示 |

## 基本的な操作の流れ

戦闘開始前は、部隊をマウスでドラッグして初期配置を変更できます。必要に応じて初期目標や待機時間を設定します。

戦闘開始後は、部隊や武将を選択して戦況を確認します。`Ctrl` + マウスホイールでマップを拡大・縮小でき、`←` / `→` キーで選択中の武将を順に切り替えられます。

表示を整理したい場合は、`Shift`で吹き出しデータを非表示、`Ctrl`でカーソルを非表示にできます。`Ctrl` + 左クリックでは兵士アニメーションの表示／非表示を切り替えられます。
