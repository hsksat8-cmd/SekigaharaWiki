# 戦績とランキング

[English version](../en/gameplay/results-and-rankings.md)

勝敗後は戦績表を確認できます。

## 武将別戦績

各武将の戦績とランキングが表示されます。

## 累積ランキング

各戦いで得られた得点を累積し、ランキングとして表示します。

## 陣営別総合得点

シナリオおよびサブシナリオ別に、東軍と西軍の総合得点が表示されます。

## 過去の上位得点

過去の上位5得点も合わせて表示されます。

この機能により、単に勝敗を見るだけでなく、同じ条件での再試行や、異なる布陣・指揮による成果を比較できます。

!!! note
    Microsoft Storeの説明には、得点計算式の詳細までは記載されていません。
