# 実験

[English version](../en/experiments/index.md)

関ヶ原IF布陣シミュレータで行った比較実験を、この章にまとめています。各ページでは、実験条件、試行結果、観察された傾向を掲載しています。

実験結果は、記載された条件と試行回数の範囲で確認された傾向です。乱数、初期配置、兵力、陣形、鉄砲足軽比率、部隊戦術などによって結果は変化します。

## 実験一覧

- [陣形と鉄砲足軽比率の実験](../formations/experiments.md)  
  5種類の陣形と鉄砲足軽比率を比較し、同数戦・兵力差戦での相性や損耗の違いを検証します。
- [挟撃実験](../formations/pincer-experiment.md)  
  正面部隊と背面部隊で敵を挟撃し、陣形・鉄砲足軽比率・兵力差による損害交換の違いを比較します。
- [部隊戦術実験](../systems/unit-tactics-experiment.md)  
  「突撃」「攻撃的」「通常」「守備的」などの部隊戦術が、1対1や挟撃でどのように結果へ影響するかを比較します。
