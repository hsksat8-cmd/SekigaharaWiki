# 挟撃総合実験

[English version](../../en/experiments/pincer/index.md)

[実験一覧](../index.md)

正面部隊と背面部隊で敵を挟み込む**挟撃**について、陣形、鉄砲足軽比率、部隊戦術などの条件を変えて行った実験をまとめています。

挟撃では、正面部隊には敵を引きつけて拘束する役割、背面部隊には敵の背後から継続して圧力を加える役割があります。そのため、同じ陣形や鉄砲足軽比率でも、正面と背面では効果が異なる場合があります。

## 実験一覧

- [挟撃実験](../../formations/pincer-experiment.md)  
  正面5,000人・背面5,000人の西軍が中央の東軍を挟撃する条件で、陣形・鉄砲足軽比率・兵力差による損害交換の違いを比較した総合的な実験です。
- [背面部隊の縦深陣形と鉄砲比率の比較](rear-deep-matchlock.md)  
  東軍12,200人に対し、西軍正面を縦深30%・通常、背面を縦深・突撃に固定し、背面の鉄砲足軽比率30%と45%を比較します。
