# 縦深 対 方形

同規模・同一パラメータの2部隊を使い、縦深と方形を入れ替えて2回戦わせる実験です。

## 実験1

- 東軍：縦深
- 西軍：方形
- その他の条件：同一

## 実験2

- 東軍：方形
- 西軍：縦深
- その他の条件：同一

## 確認された傾向

2回とも、縦深側が中央へ強い圧力をかけ、方形側を分断しやすい展開になりました。分断後は、縦深側が孤立した部分を各個撃破します。

陣形を入れ替えると有利な陣営も入れ替わるため、この条件では武将パラメータではなく、縦深と方形の相性が結果へ大きく影響したと考えられます。

!!! caution
    これはゲーム内の特定条件における検証です。兵力差、地形、複数部隊の干渉、疲労、包囲などが加わると結果は変わります。
