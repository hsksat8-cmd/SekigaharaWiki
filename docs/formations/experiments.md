# 陣形と鉄砲足軽比率の実験

[English version](../en/formations/experiments.md)

陣形実験1シナリオを使用し、**鉄砲足軽の比率と陣形の組み合わせ**によって戦闘結果がどのように変化するかを比較しました。

今回の実験は、鉄砲足軽比率を0～70%まで総当たりしたものではなく、主に次の2条件を比較しています。

- 同数戦での**鉄砲45%対30%**と、5陣形の総当たり
- 兵力差戦での**両軍鉄砲30%**と、ユーザー武将1側の陣形差

したがって、このページでは「各陣形における鉄砲足軽比率の適性」と「現在の設定における陣形相性」を示します。すべての鉄砲足軽比率について最適値を証明するものではありません。

## 共通条件

| 項目 | 条件 |
|---|---|
| シナリオ | 陣形実験1 |
| 1ドット | 10人 |
| 試行回数 | 各条件10回 |
| 決着ターン上限 | 720ターン |
| 結果表記 | 武将1勝–武将2勝 / 平均決着T / 平均残存兵数（武将1–武将2） |

平均決着ターンが720.0の条件には、部隊壊滅ではなく**午後8時の兵力優勢判定**まで戦闘が続いた試行が含まれます。

### 陣形ごとの成績

ユーザー武将1側の陣形ごとに50試行を集計すると、次の結果になりました。

| 武将1陣形 | 勝敗 | 勝率 | 評価 |
|---|---:|---:|---|
| 方形 | 10–40 | 20% | 防御的だが、射撃戦の主導権を得にくい |
| 方形自由 | 13–37 | 26% | 安定型だが、45%鉄砲の長所を最大化しにくい |
| 鶴翼 | 36–14 | **72%** | 最も高成績。広い射線を活かしやすい |
| 縦深 | 1–49 | **2%** | 最も不利。高い鉄砲比率との相性が悪い |
| 魚鱗 | 28–22 | 56% | 攻勢と射撃の中間。鶴翼にはやや不利 |

## 同数戦の考察

### 鶴翼は高めの鉄砲比率と相性がよい

鉄砲45%の鶴翼は、方形、方形自由、縦深に対して大きく勝ち越しました。特に方形自由と縦深に対しては**10勝0敗**でした。

鶴翼は部隊の横幅を確保しやすく、鉄砲足軽が前列の味方に射線を遮られにくい陣形です。敵が中央へ集中した場合にも、両翼から多数の鉄砲足軽が射撃に参加しやすくなります。

### 縦深は高い鉄砲比率を活かしにくい

縦深は50試行で**1勝49敗**でした。

正面幅が狭いため、前列が接敵すると後続の鉄砲足軽が射線を失いやすくなります。また、鉄砲足軽の比率が高い場合は、槍足軽・騎馬による前線維持と護衛に使える兵力も減少します。

縦深は突破や近接戦を重視する運用に向き、高い鉄砲足軽比率には適していません。

### 魚鱗は攻勢的な対抗策になる

魚鱗は方形、方形自由、縦深に勝ち越しました。一方、鶴翼に対しては**4勝6敗**でした。

魚鱗は敵へ前進し、接近戦へ持ち込みやすいため、敵鉄砲足軽の射撃機会を減らすことができます。ただし、鶴翼の広い正面を突破しきれない場合は、前進中に射撃を受け続けます。

### 方形・方形自由は安定型だが、火力特化には不利

方形と方形自由は縦深には優位でしたが、鶴翼・魚鱗には不利な結果となりました。

守勢や安定した運用には向きますが、高い鉄砲比率によって射撃戦の主導権を取る用途では、鶴翼ほどの効果は得られませんでした。

なお、**同じ陣形同士でもユーザー武将1側が常に有利になるわけではありません**。鉄砲比率だけでなく、初期位置、東西の進行方向、射線が形成される順序、騎馬・護衛の位置なども結果に影響します。

## 兵力差戦：両軍鉄砲足軽30%

### 条件

- ユーザー武将2：方形自由、鉄砲足軽30%
- ユーザー武将1：鉄砲足軽30%で陣形のみ変更
- 5,000対10,000、および10,000対5,000
- 5陣形 × 2兵力条件 × 10回、計100試行

### 武将1：5,000人／武将2：10,000人

| 武将1陣形 | 結果 |
|---|---|
| 方形 | 0–10 / 370.4 / 10–6,204 |
| 方形自由 | 0–10 / 359.1 / 10–6,209 |
| 鶴翼 | 0–10 / 353.1 / 10–6,452 |
| 縦深 | 0–10 / 349.7 / 10–6,575 |
| 魚鱗 | 0–10 / 363.4 / 10–6,158 |

### 武将1：10,000人／武将2：5,000人

| 武将1陣形 | 結果 |
|---|---|
| 方形 | 10–0 / 316.7 / 6,264–10 |
| 方形自由 | 10–0 / 333.8 / 6,365–10 |
| 鶴翼 | 10–0 / **259.0** / **6,968–10** |
| 縦深 | 10–0 / 302.3 / 6,035–10 |
| 魚鱗 | 10–0 / 337.7 / 6,141–10 |

## 兵力差戦の考察

兵力が2倍の場合、両軍の鉄砲足軽比率を30%に揃えた条件では、**陣形だけで兵力差を覆すことはできませんでした**。

- 5,000人側は全50試行で敗北
- 10,000人側は全50試行で勝利
- 劣勢側では魚鱗が敵の平均残存兵力を最も少なくした
- 優勢側では鶴翼が最も速く決着し、平均残存兵力も最大
- 縦深は比較的早く決着する一方、優勢側でも残存兵力が少なく、近接戦での損耗が大きい

この条件では、陣形によって**勝敗そのものよりも、決着速度や損耗の程度に差が現れました**。

## 鉄砲足軽比率の目安

今回の結果をもとにすると、各陣形では次の比率が目安になります。

| 陣形 | 鉄砲足軽比率の目安 | 主な用途 |
|---|---:|---|
| 方形 | 25～35% | 守勢・安定運用 |
| 方形自由 | 25～35% | 標準編成・汎用運用 |
| 鶴翼 | **40～50%** | 射撃戦・広い正面での火力運用 |
| 縦深 | **0～20%** | 突破・近接戦重視 |
| 魚鱗 | 20～30% | 前進圧力・攻勢運用 |

現時点の既定案である**「鶴翼45%、縦深15%、その他30%」**は、今回の実験結果と整合しています。

鉄砲足軽は、単純に数を増やすだけで強くなる兵種ではありません。広い射線、槍足軽・騎馬による護衛、敵が接近した際の前線維持が揃ったときに、高い鉄砲足軽比率を活かすことができます。
