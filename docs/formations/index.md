# 陣形の概要

Version 2.2.0から、部隊は次の5陣形を選択できます。

| 陣形 | 概要 |
|---|---|
| 方形 | まとまりを維持する基本陣形 |
| 方形自由 | 維持ターン0の方形。既定の陣形 |
| 鶴翼 | 接敵面を広げ、規模差のある戦いでも対応しやすい |
| 縦深 | 同規模戦で強い中央圧力を持つが、規模差に脆い |
| 魚鱗 | 鶴翼に対して優位を持ち、規模差への対応力も比較的高い |

## 陣形維持

- 方形自由：維持ターン0
- 方形・鶴翼・縦深・魚鱗：敵に接するまで最大50ターン維持
- 既定：方形自由

## 相性

投稿で説明されている相性は次のとおりです。

- 同規模では縦深が全般的に強い
- 鶴翼は同規模戦では全般的に劣る
- ただし鶴翼は縦深とほぼ互角に戦える
- 方形は方形自由に優位
- 魚鱗は鶴翼に優位
- 規模差がある場合、鶴翼が最も対応しやすい
- 規模差への対応は魚鱗が次点
- 規模差がある場合、縦深が最も脆い
