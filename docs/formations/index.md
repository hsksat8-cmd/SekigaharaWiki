# 陣形の概要

[English version](../en/formations/index.md)

実験によると、各陣形には次のような特徴があります。

![Version 2.2.0の陣形例](../assets/images/v2-2-0-formations-example.jpg){ .wiki-image }
<p class="image-caption">5種類の陣形</p>

| 陣形 | 鉄砲導入後の特徴 | 向く運用 | 弱点 |
|---|---|---|---|
| 方形 | 密集して守りやすく、鉄砲足軽の護衛もまとまりやすい。 | 中央を固め、鉄砲30%前後で正面から安定して戦う。敵の突撃を受け止めてから槍・騎馬で鉄砲足軽へ反撃。 | 射線が味方で塞がりやすい。高い鉄砲比率では、前列の密集が後列の発砲機会を減らす。 |
| 方形自由 | 方形より射線と兵の融通が利く、均衡型。 | 鉄砲30～45%程度。戦線に応じて広がり、味方の射線を保ちながら護衛も残す。 | 両翼への圧力や包囲性能は鶴翼ほど高くない。鉄砲60%では槍・騎馬の護衛密度が不足しやすい。 |
| 鶴翼 | 両翼に鉄砲足軽を展開しやすく、横方向から複数の射線を作れる。敵を包み込むほど側面・後方圧力も加わる。 | 鉄砲比率を高める運用に最適。中央に槍・騎馬の護衛を残し、両翼の鉄砲で削ってから包む。 | 両翼が敵槍・騎馬に先に踏み込まれると、耐久の低い鉄砲足軽が崩れやすい。兵数差が大きい戦いでは翼を広げすぎない方がよい。 |
| 縦深 | 前後に厚く、突破や正面圧力には強いが、後列の鉄砲が前列に遮られやすい。 | 鉄砲は控えめにして前後列に混ぜる。槍・騎馬を前に置き、敵鉄砲足軽を素早く突撃で崩す用途。 | 高鉄砲比率との相性はよくない。前進時に射線が詰まり、鶴翼・魚鱗の側面射撃を受けやすい。 |
| 魚鱗 | 前方への攻勢と横方向の広がりを両立し、鉄砲の射線も比較的作りやすい。 | 中～高鉄砲比率向き。前面の槍・騎馬で敵鉄砲足軽へ圧力をかけ、後続・側面の鉄砲で支援する。 | 鶴翼の広い包囲・両翼射撃には弱い。前面が止まると、鉄砲足軽が撃つ位置を失いやすい。 |

詳しい試行条件、総当たり結果、兵力差戦の比較は[陣形と鉄砲足軽比率の実験](experiments.md)にまとめています。

## 実戦的な使い分け

- **鉄砲30%前後:** 方形自由・魚鱗が扱いやすい。槍足軽と騎馬による近接戦が主で、鉄砲は支援。
- **鉄砲45～60%:** 鶴翼が有力。射線を広く取りつつ、残る槍・騎馬を護衛と敵鉄砲足軽への突撃に集中させる。
- **鉄砲60%超相当の構成:** 火力は高い一方、護衛が不足しやすい。鶴翼でも、敵が接近する前に射撃で崩せないと脆い。
