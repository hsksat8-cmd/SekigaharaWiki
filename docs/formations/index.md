# 陣形の概要

[English version](../en/formations/index.md)

実験によると、各陣形には次のような特徴があります。

![Version 2.2.0の陣形例](../assets/images/v2-2-0-formations-example.jpg){ .wiki-image }
<p class="image-caption">5種類の陣形</p>

## 方形

正面戦闘用の基本形です。前後・左右の厚みが比較的均等で、損害を局所化しにくく、主力を正面で受け止める用途に向きます。総合成績は最上位です。

あらゆる場面で万能で、既定の陣形である方形自由に対しても優位です。ユーザー武将を投入するときには第一候補になります。

## 方形自由

最初から隊形維持をせず、ドットが目標や局地状況へ追従しやすい形です。味方の隙間を埋める、接敵後に自然に密集する、側面へ回り込む、といった機動的な支援に向きます。

## 鶴翼

正面戦闘には弱く、敵が別部隊と正面接敵しているときの側面投入に向きます。両翼が敵の横へ届けば、側面・背面判定を作りやすくなります。単独で主力へ正面投入する用途には向きません。

特に敵の正面へ投入するのはかなり不向きです。敵の側面や背面が固定されている状況で使うべき陣形です。

## 縦深

横幅を狭めて奥行きを増すため、狭い突破口への投入、敵前線の切れ目への集中、鶴翼の中央突破に最適です。正面の広い方形・魚鱗には側面を取られやすく、不利です。

少数の敵を短時間で撃破したいときにも有効です。

## 魚鱗

前方を尖らせた楔形で、敵の一点へ圧力を集中する攻撃形です。弱った前線、側面、背面のいずれか一点へ刺し込む用途に向きます。方形と並んで最も安定して強い形です。

## 適切な使い分け

主力正面には方形、突破・一点攻撃には魚鱗、隙間への投入には縦深、追従・支援には方形自由、敵が固定された後の側面攻撃には鶴翼という分担が適切です。
