# 陣形の概要

[English version](../en/formations/index.md)

部隊の陣形は、方形、方形自由、鶴翼、縦深、魚鱗の5種類から選択できます。

![Version 2.2.0の陣形例](../assets/images/v2-2-0-formations-example.jpg){ .wiki-image }
<p class="image-caption">5種類の陣形が追加されたVersion 2.2.0の画面例</p>

## 陣形維持

- 方形自由は維持ターン0の方形
- 方形、鶴翼、縦深、魚鱗は、敵に接するまで最大50ターン陣形を維持
- 既定の陣形は方形自由

## 同規模の部隊同士

- 縦深は他の陣形より強い
- 鶴翼は全体として他の陣形より劣る
- ただし、鶴翼は縦深にほぼ互角に戦える
- 方形は方形自由に対して優位
- 魚鱗は鶴翼に対して優位

## 規模が異なる場合

- 相手が少数でも多数でも、鶴翼が最もうまく戦える
- 次に魚鱗
- 縦深は最も脆い

!!! info "情報源"
    上記の関係はMicrosoft Storeの現行製品説明と、Version 2.2.0のX投稿に記載されたゲーム内特性です。実際の結果は地形、士気、疲労、複数部隊の干渉などによって変化します。
