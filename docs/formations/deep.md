# 縦深

[English version](../en/formations/deep.md)

## 鉄砲導入後の特徴

前後に厚く、突破や正面圧力には強いが、後列の鉄砲が前列に遮られやすい。

Version 2.6.0では、後衛で鉄砲足軽の比率を高めています。

## 向く運用

鉄砲は控えめにして前後列に混ぜる。槍・騎馬を前に置き、敵鉄砲足軽を素早く突撃で崩す用途。

## 弱点

高鉄砲比率との相性はよくない。前進時に射線が詰まり、鶴翼・魚鱗の側面射撃を受けやすい。
