| [毛利・小早川西軍積極参戦](mori-kobayakawa-western.md) | 毛利隊と小早川隊がともに西軍として参戦 |
| [完全ランダム](random.md) | 武将能力や戦況が変化する予測困難な戦い |
| [ランダム架空大戦](random-fictional-war.md) | 広大な戦場と多数の部隊による架空の大規模合戦 |
