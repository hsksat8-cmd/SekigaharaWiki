# シナリオ一覧

[English version](../en/scenarios/index.md)

ゲーム本体のシナリオ選択メニューと同じ名称で掲載しています。

## 基本・勢力差

| シナリオ | 概要 |
|---|---|
| [史実寄り](historical.md) | 通常の関ヶ原配置。東軍開始士気 +3で、小早川は戦況に応じて寝返り判定を行います。 |
| [西軍有利](western-advantage.md) | 西軍開始士気 +7。小早川の寝返りが起きにくく、毛利・島津も動きやすい設定です。 |
| [東軍有利](eastern-advantage.md) | 東軍 +5、西軍 -5。小早川と追随勢の寝返りが起きやすく、東軍が早期に主導権を取りやすい設定です。 |

## 小早川・毛利・島津の行動差

| シナリオ | 概要 |
|---|---|
| [小早川静観](kobayakawa-neutral.md) | 小早川本隊と追随4隊が静観し、寝返りません。 |
| [小早川・毛利静観](kobayakawa-mori-observe.md) | 小早川に加えて毛利秀元・吉川広家も静観寄り。現在の体験版で唯一選択できます。 |
| [毛利参戦](mori-joins.md) | 毛利勢の参戦確率が通常より高く、西軍開始士気 +4。 |
| [島津積極策](shimazu-active.md) | 島津隊が開戦時から積極状態になり、中央・南側へ参加しやすくなります。 |
| [毛利積極参戦](mori-active.md) | 毛利秀元・吉川広家が開戦直後から西軍として前進。西軍開始士気 +8。 |
| [毛利積極参戦・小早川静観](mori-active-kobayakawa-observes.md) | 毛利勢は積極参戦し、小早川勢は静観を続けます。 |
| [小早川西軍積極参戦](kobayakawa-western.md) | 小早川本隊と追随4隊が西軍のまま即時攻勢。西軍 +10、東軍 -3。 |
| [毛利・小早川西軍積極参戦](mori-kobayakawa-western.md) | 毛利・小早川がともに西軍で積極参戦。西軍 +14、東軍 -6。 |

## ランダム戦

| シナリオ | 概要 |
|---|---|
| [完全ランダム](random.md) | 通常配置で武将ごとの士気・積極性・忠誠・逡巡度をランダム化します。 |
| [兵数を含む完全ランダム](random-with-troop-counts.md) | 完全ランダムに各部隊の兵数ランダム配分を加えます。 |
| [ランダム架空大戦](random-fictional-war.md) | 4倍の広域マップに追加大名を配置し、能力や初期位置も変化します。 |
| [兵数を含むランダム架空大戦](random-fictional-war-with-troop-counts.md) | ランダム架空大戦に各部隊の兵数変動を加えます。 |
