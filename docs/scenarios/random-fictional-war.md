# ランダム架空大戦

[English version](../en/scenarios/random-fictional-war.md)

4倍の広域マップに、上杉・伊達・前田・立花・丹羽など8隊の追加大名を配置します。士気・武将特性に加え、指定された地域内で部隊の初期位置も入れ替わります。小早川勢は最初の400ターン静観し、その後200ターンで累積50%となる確率で、損失が少ない側に参戦します。

Version 2.7.0から、中規模の**4部隊**がランダムに[全騎馬部隊](../systems/all-cavalry-units.md)になります。全騎馬となった部隊には15%の兵数削減が適用されます。

武将能力値と基準兵数を固定して比較する場合は、[架空大戦](fictional-grand-battle.md)を使用できます。
