# 架空大戦

[English version](../en/scenarios/fictional-grand-battle.md)

4倍の広域マップに、関ヶ原の全隊へ有力大名12隊を加えた架空決戦です。

- 武将能力値・基準兵数は下表の固定値です。能力値のランダム補正は入りません。
- 配置枠は同じ陣営内の指定グループでランダムに入れ替わります。
- 小早川秀秋隊と付随4隊は最初の400ターン静観し、その後は200ターン累積50%の確率で参戦します。参戦先は、その時点で損害が少ない軍ほど選ばれやすくなります。
- 「兵数を含むランダム架空大戦」と異なり、兵数はランダム化されません。
- 基準総兵数は東軍105,700人、西軍130,500人、計236,200人です。

開始士気はゲーム内の正規化後の値です。略記は、積=積極性、忠=忠誠、躊=躊躇、統=統率、指=指揮信頼です。
