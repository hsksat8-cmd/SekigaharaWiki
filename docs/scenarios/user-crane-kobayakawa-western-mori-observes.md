
# ユーザー武将鶴翼参戦 - 小早川西軍積極参戦・毛利静観

[English version](../en/scenarios/user-crane-kobayakawa-western-mori-observes.md)

[小早川西軍積極参戦・毛利静観](kobayakawa-western-mori-observes.md)と同じ条件に加え、西軍側にユーザー武将1が追加されます。

- 兵数: 7,500
- 初期陣形: 鶴翼
- 鉄砲足軽比率: 30%
- 初期は75ターン待機
- 陣形維持: 50ターン
- 配置後は指定地点へ進出

小早川勢の攻勢と連携できる鶴翼部隊を、ユーザーが指揮して介入するための既定シナリオです。
