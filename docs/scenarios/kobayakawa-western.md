# 小早川西軍参戦シナリオ

小早川秀秋隊が最初から西軍へ参加するIFシナリオです。

投稿では、この条件では西軍がかなり有利になると説明されています。徳川家康隊は中央突破を狙う場合がありますが、各個撃破の方が有効になる局面もあります。

Version 2.0系の動画では、更新された地形と兵士アニメーションを使って、このシナリオの戦況が紹介されています。
