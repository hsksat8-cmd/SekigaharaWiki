# 史実寄り

[English version](../en/scenarios/historical.md)

通常の関ヶ原配置です。東軍は開始士気が +3。小早川は東軍優勢・大谷隊の消耗・西軍士気低下などを受けて寝返り判定を行います。毛利勢は基本的に静観寄りです。

Version 2.8.0では、**徳川家康隊の前進**と**小早川秀秋隊の寝返り**がより史実に近いタイミングで起きるよう調整されています。正確な発生ターン・時刻は、この更新情報では指定されていません。

また、通常マップで毛利秀元隊がIF参戦した場合、**南宮山北側**での戦いが再現されます。詳しくは[毛利参戦](mori-joins.md)をご覧ください。
