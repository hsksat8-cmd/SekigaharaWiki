# 史実寄りシナリオ

史実寄りシナリオでは、関ヶ原の初期配置や参戦関係を史実に近い形で設定します。

## 西軍側の難しさ

小早川秀秋の寝返りがあるため、西軍が徳川家康隊へ対応できても、その後に戦況が崩れる場合があります。

ただし、次の条件が重なると西軍にも勝機があります。

- 小早川秀秋の寝返りが遅い
- 毛利秀元・吉川広家の参戦が早い
- 島津義弘が有効に参戦する
- ユーザー武将が局所的に成果を上げる

同じ状況で再戦しても、結果が大きく変わる例が投稿されています。
