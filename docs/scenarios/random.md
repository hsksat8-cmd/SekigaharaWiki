# 完全ランダム

[English version](../en/scenarios/random.md)

武将の能力や戦況が変化し、予測困難な戦いが展開するシナリオです。

## ランダム化される要素

Microsoft Storeの説明では、武将の能力と戦況が変化するとされています。

Xの開発投稿では、ランダム系シナリオについて次の補足があります。

- 武将ごとの兵力が変動する場合がある
- 指揮官の能力値が変化する場合がある
- 参戦判断が史実寄りシナリオほど戦況に結び付かない場合がある

!!! note
    ランダム化の具体的な範囲は、ゲームのバージョンや選択するサブシナリオによって異なる可能性があります。
