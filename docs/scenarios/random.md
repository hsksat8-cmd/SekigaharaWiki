# ランダムシナリオ

ランダム系シナリオでは、戦況が毎回大きく変化します。

## 兵数を含むランダムシナリオ

両軍の総兵数は変わりませんが、各武将のパラメータに加え、各部隊の兵数が0.5～2倍の範囲で変化します。

## 参戦

史実寄りのシナリオでは戦況を見て参戦する武将も、ランダム系では戦況にあまり関係なくランダムに参加します。

対象として投稿で挙げられているのは次の部隊です。

- 小早川秀秋隊
- 毛利秀元隊
- 吉川広家隊
- 島津義弘隊
