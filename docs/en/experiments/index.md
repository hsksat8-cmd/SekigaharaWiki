# Formation Experiments

[日本語版](../../experiments/index.md)

Formation experiments compare formations while keeping other conditions equal.

## Basic Conditions

- Player-Created Commander 1 and Player-Created Commander 2 have identical parameters
- Each commands 5,000 troops
- Each army commander unit has 10 troops
- The army commander units remain stationary for 600 turns
- Only the tested formations are changed

This isolates the effect of the formation matchup.
