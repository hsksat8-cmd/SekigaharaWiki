# Game Overview

[日本語版](../../game/overview.md)

**Sekigahara: What-If Battle Simulator** is a formation-based simulation in which the commanders and soldiers of the Eastern and Western Armies fight as large groups of dots or animated characters.

After the battle begins, each unit acts autonomously according to its objectives and the current situation. You can leave the battle running in a corner of the screen while working, or change the deployment and scenario to compare different outcomes.

## Core Strategic Idea

Victory depends not only on troop strength, but also on unit positioning and the concentration of force.

Because the Western Army has a weaker main force, it benefits from encircling enemies with multiple units and defeating isolated units in detail. The Eastern Army, led by the powerful Tokugawa Ieyasu unit, can instead attempt a central breakthrough and directly target the enemy commander.

The best strategy changes with the battlefield and deployment.

- Prioritize an advance toward the enemy commander
- Protect your own commander
- Encircle enemy units and reduce their combat strength
- Destroy isolated units in sequence
- Seek a rapid decision through a central breakthrough

## Main Features

| Category | Feature |
|---|---|
| Battle presentation | Large battles shown with soldier dots or animated soldiers |
| Representation scale | One dot or character represents 10 or 20 soldiers |
| Unit behavior | Commanders and units act autonomously |
| Participation | Observe, command the Eastern Army, or command the Western Army |
| Formations | Square, Flexible Square, Crane Wing, Deep, and Fish Scale |
| Strategy | Encirclement, defeat in detail, central breakthrough |
| Deployment editing | Drag units to change their initial positions |
| Sub-scenarios | Save commander placement, initial objectives, and waiting times |
| Data transfer | Import and export groups of sub-scenarios |
| Observation support | Real-time subtitles and commander-detail switching |
| Results | Commander records, rankings, cumulative scores, and army scores |
| Display controls | Zoom mode and 1× to 50× map magnification |
