
# User Commander Crane Wing — Kobayakawa Fights for the West, Mori Observes

[日本語版](../../scenarios/user-crane-kobayakawa-western-mori-observes.md)

This uses the same scenario conditions as [Kobayakawa Fights for the West, Mori Observes](kobayakawa-western-mori-observes.md), while adding User Commander 1 to the Western Army.

- Troops: 7,500
- Initial formation: Crane Wing
- Matchlock ratio: 30%
- Initial wait: 75 turns
- Formation hold: 50 turns
- Then advances toward the assigned point

It is intended for player-directed intervention: a Crane Wing unit supports and coordinates with Kobayakawa’s Western offensive while the Mori forces remain observers.
