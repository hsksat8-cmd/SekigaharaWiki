# Random Fictional Grand Battle with Troop Counts

[日本語版](../../scenarios/random-fictional-war-with-troop-counts.md)

Adds unit-by-unit troop-count variation to Random Fictional Grand Battle. Total troop strength for each army is preserved, but individual unit sizes change. Kobayakawa's main unit and four accompanying units are excluded from the random troop-count changes.

Starting with Version 2.7.0, **four medium-sized units** are randomly converted into [All-Cavalry Units](../systems/all-cavalry-units.md). Units converted in this way receive the 15% troop-strength reduction.
