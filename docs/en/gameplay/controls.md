# Keyboard and Mouse Controls

[日本語版](../../gameplay/controls.md)

## Mouse Controls

| Control | Action |
|---|---|
| Left click | Select a unit, commander, or UI item |
| Left drag | Move a unit's initial deployment position |
| `Ctrl` + left click | Toggle soldier animations on or off |
| `Ctrl` + mouse wheel | Zoom the map in or out |
| Right click | Set a movement destination or attack target for a unit |
| Drag on the map | Move the map view |

## Keyboard Controls

| Key | Action |
|---|---|
| `Esc` | Clear the current selection or close a menu |
| `Space` | Pause or resume |
| `←` / `→` | Switch the selected commander |
| `Shift` | Hide speech-bubble data |
| `Ctrl` | Hide the cursor |

## Basic Operation Flow

Before the battle begins, units can be dragged to change their initial deployment positions. Initial targets and waiting times can also be set as needed.

After the battle begins, select units or commanders to follow the situation. Use `Ctrl` + mouse wheel to zoom the map, and use the `←` / `→` keys to cycle through the selected commanders.

For a cleaner view, hold `Shift` to hide speech-bubble data and `Ctrl` to hide the cursor. Use `Ctrl` + left click to toggle soldier animations on or off.
