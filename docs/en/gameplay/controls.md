# Controls and Menus

[日本語版](../../gameplay/controls.md)

## Controls and Menus

### Participation

Choose who you control.

- **Observe**: all units are AI-controlled.
- **Join Eastern Army / Join Western Army**: issue orders to participating commanders on that side.

The side cannot be changed after the battle starts.

### Start / Pause

Starts, pauses, or resumes turn progression. The button changes to Pause while the battle is running.

### Reset

Recreates the initial battle using the current scenario, soldiers-per-dot setting, HP scale, and subscenario settings, with a new random seed.

### Language

Switches the interface, unit details, battle status, and captions between Japanese and English.

### Speed

Changes the time between turns.

- Slow
- Normal
- Fast

This changes display speed only, not battle rules.

### Decide winner at 8 PM

- **On**: at 8 PM, the army with more remaining troops wins by advantage.
- **Off**: the battle continues beyond 8 PM, normally until an army commander is defeated.

This cannot be changed during a battle or replay.

### Scenario

Select a standard scenario, formation experiment, or saved subscenario. Changing it resets the battle.

### Save subscenario

Saves initial placement, commander states, targets, waiting periods, formations, and formation-hold turns. Available before the battle starts.

### Rename / Delete

Renames or removes the selected saved subscenario.

### Join as commander

Select an existing commander to control, or create a user commander. Up to three commanders may participate. User commanders can have custom troop strength, abilities, placement, target, formation, and formation-hold turns.

### Remove user commander

Removes an added user commander from the current battle.

### Remove commanders

Removes selected scenario commanders from the current battle or saved subscenario. Default scenarios remain unchanged.

### Export / Import subscenarios

Saves all subscenarios to a file or loads them from one.

### Per dot

Sets how many soldiers one troop dot represents: 10 or 20. Changing it recreates the initial state.

### Dot HP

Sets the durability of all troop dots to 1/4×, 1/2×, Standard, 2×, 4×, or 8×. Changing this setting recreates the initial state. Higher values increase the number of turns before the battle is decided, making them useful when you want more time to consider the situation. In the mode that determines the winner based on the situation at 8 PM, the result is decided by the number of troops remaining at 8 PM. Therefore, higher Dot HP values favor the Western Army, which begins with the larger total force.

### Captions

Shows or hides automatic battle captions. It does not affect battle results or logs.

### Battle Results

Opens current battle rankings, side scores, and cumulative rankings.

### Automatic Overview button

Toggles Automatic Overview Mode on or off.

### `<<` / `>>` buttons

Returns to the previous scene or advances to the next scene in Automatic Overview Mode.

## Top Controls

### Official Wiki

Opens the official wiki in the selected language.

### Screen zoom

Zooms the entire application, including the map, menus, and text.

### Map zoom

Zooms only the battlefield map from 1× to 50×. At zoom above 1×, drag an empty map area with the left mouse button to pan.

## Keyboard Controls

| Key | Action |
|---|---|
| `Enter` | Start / pause the battle |
| `←` / `→` | Select the previous / next unit |
| `Shift` | Hide unit callouts; also clears the current callout |
| `Ctrl` | Hide the cursor over the map |
| `Ctrl` twice quickly | While hovering a unit, show its name, troop count, and morale as a 4-second caption |
| `Ctrl` + left click | Toggle animation view on/off |
| `Ctrl` + mouse wheel | Zoom the map around the cursor |
| `Esc` | Cancel target or placement selection |

## Mouse Controls

| Control | Action |
|---|---|
| Hover a unit dot or banner | Show its unit data |
| Left click a unit dot or banner | Select that unit |
| Right click a controllable unit or banner | Open the unit command dialog |
| Drag an empty map area | Pan the map when map zoom is above 1× |
| Before the battle begins, drag a unit dot | Move that unit’s initial position |
| Left click while choosing a target or placement | Confirm the selected map position |

Left- or right-clicking the map clears the currently displayed unit callout.
