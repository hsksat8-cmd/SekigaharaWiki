# Sub-Scenarios

[日本語版](../../gameplay/subscenarios.md)

Customized conditions can be saved as sub-scenarios.

## Saved Information

The Microsoft Store product description explicitly lists:

- Placement of created commanders
- Initial objectives
- Initial waiting times

## Editing Initial Deployment

Units can be dragged to freely change their initial positions. Deployment affects contact order, encirclement, central breakthroughs, and protection of the army commander.

## Import and Export

Groups of sub-scenarios can be imported and exported.

This allows customized conditions to be archived or moved together.

!!! note
    The Microsoft Store description does not specify the file format or storage location.
