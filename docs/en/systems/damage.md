# Damage Calculation

[日本語版](../../systems/damage.md)

An archived post gives the following weighting for damage and defense.

## Attack

| Factor | Weight |
|---|---:|
| Unit attack | 46% |
| Unit morale | 18% |
| Soldier-dot morale | 28% |
| Leadership | 8% |

## Defense

| Factor | Weight |
|---|---:|
| Unit defense | 48% |
| Unit morale | 18% |
| Soldier-dot morale | 26% |
| Leadership | 8% |

!!! note
    The archived X post is truncated, so only the confirmed weights are shown here. The source does not confirm whether additional random factors or modifiers are applied.
