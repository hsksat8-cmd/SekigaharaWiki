# Battle System

[日本語版](../../systems/index.md)

Battle results are shaped by the following elements:

- Unit types
- Unit composition (Normal / All-Cavalry)
- Unit attack and defense
- Unit morale
- Soldier-dot morale
- Discipline
- Fatigue
- Encirclement
- Battlefield momentum
- Formation
- Unit separation and defeat in detail

Starting with Version 2.7.0, unit composition can be set to **Normal** or **All-Cavalry**. See [All-Cavalry Units](all-cavalry-units.md) for details.

Version 2.8.0 adds [flank/rear tactical restrictions](flank-rear-engagement.md) and [morale penalties](morale.md), as well as [fatigue-related HP loss](damage.md) for individual soldier dots.
