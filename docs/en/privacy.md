# Privacy

[日本語版](../privacy.md)

This wiki uses **Cloudflare Web Analytics** to understand how the site is used.

## Information Processed

Cloudflare Web Analytics may process statistical information such as:

- Pages viewed
- Referring site
- Country or region
- Browser
- Operating system
- Device type
- Date and time of access

## Cookies

The Cloudflare Web Analytics configuration used on this wiki does not use cookies for site analytics.

## Purpose

The data is used to:

- Identify popular pages
- Improve the wiki structure
- Find pages that need clearer explanations
- Compare demand for Japanese and English content
- Improve game information

## External Links

This wiki links to Microsoft Store, X, YouTube, and other external services. Their own privacy policies apply after you leave this site.
