# User Commanders

[日本語版](../../../commanders/user/index.md)

User commanders are custom participation slots that the player can add to a battle. They can be assigned to either the Eastern Army or the Western Army, and up to three units can be added.

!!! note "Trial Version"
    In the trial version, only User Commander 1 can be added and controlled, and its troop count is fixed at 10,000. The only selectable scenario is **Kobayakawa and Mori Observe**.

For troop-setting limits in the full version, see [Limits on User-Specified Troop Increases](../../gameplay/subscenarios.md#limits-on-user-specified-troop-increases).
