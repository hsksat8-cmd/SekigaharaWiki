## Characteristics

This unit can be assigned to either the Eastern Army or the Western Army, and up to three user units can be added.

## Configurable Settings

- Name
- English name
- Position
- Troop strength
- Waiting turns
- Target (an enemy unit or a map coordinate)
- Target hold turns
- Initial formation
- Formation-hold turns

## Notes

User Commander 1, 2, and 3 are slots that allow the player to add custom participating commanders. Their base statistics are shared, and their battlefield role changes according to the selected side and settings.
