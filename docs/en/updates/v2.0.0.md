# Version 2.0.0

[日本語版](../../updates/v2.0.0.md)

## Changes
- Recreated the terrain of Sekigahara more faithfully.
- In `Ctrl` + left-click zoom mode, soldier animations make battle scenes more dynamic.
- `Ctrl` + mouse wheel can now change the map zoom level from 1× to 50×.
- Unit troop strength can now be specified in sub-scenarios.
