# Version 1.2.0

[日本語版](../../updates/v1.2.0.md)

## Changes
- The user can now join the battle at any time as either the Eastern or Western Army and control all commanders in that army. The user can also participate as up to three commanders, including user-created commanders. In this mode, the user can participate as any commander in either army, or as up to three user-created commanders with freely chosen names.
- Commanders can now be removed to allow decisive battles with a smaller number of units. Tokugawa Ieyasu's unit and Ishida Mitsunari's unit cannot be removed.
- Real-time subtitles are now displayed, adding excitement to the battle while making the situation easier to follow.
- After a battle is decided, the results table now shows each commander's record and ranking. A cumulative ranking based on points earned in each battle is also displayed. In addition, the overall scores of the Eastern and Western Armies are shown for each scenario and sub-scenario, together with the top five past scores.
- Unit behavior has been made more natural.
