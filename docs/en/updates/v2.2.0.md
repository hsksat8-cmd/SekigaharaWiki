# Version 2.2.0

[日本語版](../../updates/v2.2.0.md)

## Confirmed Changes

- Added Square, Flexible Square, Crane Wing, Deep, and Fish Scale formations
- Set Flexible Square as the default
- All formations except Flexible Square remain in shape for up to 50 turns or until enemy contact
- Added formation matchups and different suitability depending on force-size imbalance
- Added temporary retreat behavior when morale falls
- Revised unit behavior to resemble Sengoku-period commanders rather than purely game-like optimization
