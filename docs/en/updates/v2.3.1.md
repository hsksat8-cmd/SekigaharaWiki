# Version 2.3.1

[日本語版](../../updates/v2.3.1.md)

The game has been upgraded to Version 2.3.1.

## Unit Banners Added

Banners are now displayed for each unit. This makes the forces easier to distinguish and gives the battlefield the visual appeal of a Sengoku-period battle scroll.
